# 当代年轻人精神困境与解决之道

这是一个中文单页 HTML 专题项目，围绕当代年轻人的精神状态、心理困境与自我调适展开。

## 项目内容

本项目主要讨论这些主题：

- 内耗、焦虑、emo、情绪颗粒度、不配得感
- 躺平、内卷、整顿职场、孔乙己长衫
- 睡眠、运动、体检异常与心理健康
- 人格标签、自我标签化、赛博玄学
- 哲学、脑科学与现代物理视角下的“现实”“意义”“自我”

项目整体采用 **专题网页** 的形式呈现，兼顾：

- 社会观察
- 心理分析
- 哲学思考
- 文学表达
- 移动端阅读体验
